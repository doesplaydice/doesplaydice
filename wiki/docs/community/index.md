# Community

Adventures, settings, adversaries, optional rules, tools. Anything that adds to the game without
changing the one page.

## Add yours

Two doors, same result &mdash; both open a pull request:

<div class="grid cards" markdown>

-   :material-pencil: **In the browser**

    ---

    Go to <a href="../admin/" target="_blank" rel="noopener"><code>/admin/</code></a>, sign in, pick **Community modules**, write. You never touch git
    and you don't need to know what a pull request is.

-   :material-source-fork: **In git**

    ---

    Add a markdown file to `wiki/docs/community/modules/` and open a PR. See
    [CONTRIBUTING.md](https://github.com/doesplaydice/doesplaydice/blob/main/CONTRIBUTING.md).

</div>
