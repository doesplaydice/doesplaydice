Open this through the site, not the file

You've opened this page directly from disk (file://). The editor refuses to load its configuration over file:// — browsers treat every local file as a separate origin, so it can't safely fetch config.yml.

Start the site, then use the served address:
.venv/bin/mkdocs serve -f wiki/mkdocs.yml -a 127.0.0.1:8777
then open http://127.0.0.1:8777/admin/

Once it's published, this page just lives at /admin/ on the real site and none of this applies.

This page loads the Sveltia CMS bundle from a CDN. If you're offline or the CDN is blocked, it won't appear.

To run the editor with no GitHub account at all: reload this page and choose Work with Local Repository, then pick the project folder. Edits write straight to the markdown files on disk. local_backend is already enabled in config.yml.

You can also always edit the markdown in wiki/docs/ directly — the CMS is a convenience layer over the same files, not a separate store.
