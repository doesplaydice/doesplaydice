# For Narrators <span class="dpd-status stub">Coming soon</span>

Running a game is the harder half, and it's the half that decides whether someone plays once or
plays for years. This section will gather what helps a Narrator build and run a game: setting
scenes, calling for rolls, pacing a night, and prepping little so you can improvise a lot.

None of it is published yet. Until it is, everything you need to run a table is already in
[the rules](../rules/index.md), and [the screen](screen.md) puts the parts you reach for
mid-game on one page.

Written something that would help other Narrators? [Community modules](../community/index.md)
are open to anyone.
