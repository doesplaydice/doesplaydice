# Narrator's Guide

The Narrator is the game master: the GM, DM or referee, if you've played other games.
Running a game is the harder half, and it's the half that decides whether someone plays once or
plays for years. Everything you need to run a table is already in [the rules](../rules/index.md),
and [the screen](screen.md) puts the parts you reach for mid-game on one page.

## Any world you like

Does Play Dice is setting-agnostic: the rules don't assume a genre. You can run a heist, a
dinner-party murder, a dungeon, a haunted colony ship.
